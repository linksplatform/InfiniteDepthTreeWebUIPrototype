Double Tree with Dual Selection - Test Page

🎯 Implementation Features

  • ✅ Two side-by-side tree instances
  • ✅ Independent selection for each tree
  • ✅ Visual differentiation (orange vs blue selection)
  • ✅ Tab key to switch between trees
  • ✅ Shift+Arrow keys for cross-tree navigation
  • ✅ Click to focus and select items
  • ✅ Dual current item tracking

🕹️ Controls

Tab - Switch between left and right trees

↑ ↓ - Navigate up/down in active tree

← → - Navigate left/right in tree hierarchy

Shift + ← → - Switch to left/right tree and navigate

Click - Focus and select item in either tree

Ctrl/Alt + Q - Toggle query bar

🎨 Visual Indicators

  • 🟠 Orange border + text: Left tree selection
  • 🔵 Blue border + text: Right tree selection
  • Both selections can be active simultaneously

🔗 Use Cases

  • 📎 Select two elements to link them together
  • 🔄 Move elements from one tree location to another
  • 🔍 Compare different parts of the tree structure
  • ⚡ Quick navigation between related content
